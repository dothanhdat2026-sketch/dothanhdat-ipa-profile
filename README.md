# Đỗ Thành Đạt — Developer Profile

Ứng dụng iOS giới thiệu Đỗ Thành Đạt, đam mê Developer và công nghệ.

## Mở project
1. Mở `DoThanhDat.xcodeproj` bằng Xcode trên macOS.
2. Chọn Team/Signing trong Signing & Capabilities.
3. Chọn iPhone Simulator hoặc thiết bị thật.
4. Build bằng `⌘R`.

> Đây là source SwiftUI. Không thể tạo IPA đã ký trực tiếp trên môi trường này; IPA cần Xcode + signing certificate/provisioning profile của bạn.
